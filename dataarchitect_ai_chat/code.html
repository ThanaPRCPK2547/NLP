Can you write a SQL query to join the 'orders' and 'customers' tables by 'customer_id'?

terminal Query Generator

Certainly. Here is a standard inner join to retrieve order details alongside customer information:

sql 
SELECT 
    c.customer_id,
    c.customer_name,
    o.order_id,
    o.order_date
FROM orders o
JOIN customers c 
    ON o.customer_id = c.customer_id
WHERE o.order_status = 'COMPLETED';
